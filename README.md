![# portfolio

my personal portfolio site: cs undergrad at iit colombo, into cloud and devops.

**live site: https://kithminiss.github.io**

built with vite + react. all the text lives in `src/data.js`.

## run it locally

    npm install
    npm run dev      # local dev server
    npm run build    # outputs dist/

## deploying

hosted on github pages. every push to `main` runs the workflow in `.github/workflows/deploy.yml`, which builds the site and publishes it.

## writing posts

copy `src/posts/_template.md`, rename it, and edit. files starting with `_` are ignored.](image.png)
